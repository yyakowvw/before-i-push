# Contributing

Thanks for helping! The project has one hard rule: **zero runtime dependencies**. Everything uses Node's
standard library, and tests use `node:test`.

## Add a key pattern

1. Add `{ name, re }` to `PATTERNS` in `src/checks/secrets.mjs`. Anchor it on the provider's fixed prefix so
   it does not match random strings.
2. Add a fake key to `KEYS` in `test/helpers.mjs`. **Build it from two string pieces**
   (`'AKIA' + '…'`) so no scanner — including this one — sees a whole key in the repository.
3. `npm test`

## Report a false positive

Open an issue with the masked sample from the report and the kind of file it was in. Never paste a real key.

## Run it on itself

```bash
node bin/before-i-push.mjs .
```

`docs/demo.svg` is generated by `node scripts/demo-svg.mjs`.
